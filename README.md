# 🎂 SweetBakery POS & Bakery Management System
**ប្រព័ន្ធគ្រប់គ្រងហាងនំខេកស្តង់ដារកម្រិតខ្ពស់ (Enterprise Quality)**

ប្រព័ន្ធគ្រប់គ្រង និងលក់នំខេក នំប៉័ង ភេសជ្ជៈ និងការកុម្ម៉ង់នំខួបកំណើត/ពិសេស ជាមួយរូបិយប័ណ្ណពីរ (KHR ៛ & USD $) និងភាសាខ្មែរ-អង់គ្លេស។

---

## 🌟 មុខងារស្នូល (Features)

1. **លក់នៅបញ្ជរ (Touchscreen POS)**
   - បញ្ជាទិញរហ័ស គាំទ្រអេក្រង់ Touchscreen
   - ប្តូរ និងគណនាលុយជា ដុល្លារ ($) និង រៀល (៛) ដោយស្វ័យប្រវត្តិតាមអត្រាប្តូរប្រាក់ជាក់ស្តែង
   - គាំទ្រការទូទាត់ជាសាច់ប្រាក់ និងស្កេន KHQR Bakong / ABA PayWay
   - បោះពុម្ពវិក្កយបត្រម៉ាស៊ីនកម្តៅ 80mm & 58mm (Thermal Receipt) ជាមួយអក្សរខ្មែរស្អាត

2. **ផ្ទាំងតាមដាននំកុម្ម៉ង់ខួបកំណើត (Custom Cake Production Pipeline)**
   - កត់ត្រាទំហំ, រសជាតិ, អក្សរលើនំ, ចំណាំការតែង, រូបភាពគំរូ, និងម៉ោងមកយក
   - តាមដានដំណាក់កាលផលិត 5 កម្រិត (Kanban):
     `Pending (រង់ចាំទទួល)` ➔ `Baking (កំពុងដុត)` ➔ `Decorating (កំពុងតែង)` ➔ `Ready (រួចរាល់)` ➔ `Delivered (បានប្រគល់)`
   - តាមដានប្រាក់កក់ (Deposit) និងប្រាក់នៅសល់

3. **ស្តុកគ្រឿងផ្សំ & រូបមន្តនំ (Recipe & BOM Inventory)**
   - គ្រប់គ្រងគ្រឿងផ្សំដើម (ម្សៅ, ប៊័រ, ស្ករ, ស៊ុត, ក្រែម, ប្រអប់នំ...)
   - ដាស់តឿននៅពេលគ្រឿងផ្សំជិតអស់ពីស្តុក (Low Stock Alerts)
   - គណនាថ្លៃដើមផលិតនំ (Recipe Costing / BOM) និងប្រាក់ចំណេញសុទ្ធ

4. **គ្រប់គ្រងវេនការងារ (Shift & Cash Drawer)**
   - បើកវេន/បិទវេន និងផ្ទៀងផ្ទាត់សាច់ប្រាក់ក្នុងកេះ

5. **របាយការណ៍ហិរញ្ញវត្ថុ (Reports & Analytics)**
   - ស្ថិតិចំណូលប្រចាំថ្ងៃ
   - មុខនំដែលលក់ដាច់បំផុត (Top Best Sellers)
   - ទាញយករបាយការណ៍ជាឯកសារ Excel/CSV

## 🚀 របៀបដំណើរការប្រព័ន្ធ (How to Run)

### វិធីទី ១៖ ដំណើរការតាមរយៈ Command
```bash
cd C:\Users\User\.gemini\antigravity\scratch\bakery-pos-system
npm run dev
```
បន្ទាប់មកបើក Browser ទៅកាន់៖ `http://localhost:3000`

- ចុចពីរដង (Double Click) លើឯកសារ `start-app.bat` នៅក្នុង folder `bakery-pos-system` ដើម្បីបើកដំណើរការភ្លាមៗ។
